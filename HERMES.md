# Hermes Loader

This repository-local file is a compatibility entry point, not an organization-wide Hermes schema.

Load the root `SKILL.md` as the authoritative contract, then read the necessary references and use the deterministic scripts under `scripts/`. Use only predeclared factor channels and point-in-time graph snapshots. Require authorization before direct data access, evaluation, or writes. Do not train graph neural networks, handle credentials, use future graph membership, or provide investment advice.
