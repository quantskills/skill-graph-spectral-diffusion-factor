# Point-in-Time Boundary

T-day factor values and graph membership are used after the close for T+1 execution assumptions. `neighbor_lag` uses T-1 node signals; it never reads T+1 or label data.

Industry and concept snapshots must carry an effective or observed date no later than T. A current classification applied retroactively is not point-in-time evidence. Financial/event fields are excluded from v1 unless their disclosure availability contract is separately proven.
