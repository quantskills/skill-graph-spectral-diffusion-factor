# Validation Protocol

Validate in layers:

1. synthetic graph normalization, duplicate-edge, isolated-node, and deterministic fingerprint tests;
2. channel completeness and robust-standardization tests;
3. low/high decomposition and strict T-1 neighbor-lag tests;
4. schema, freeze, qsh-form, and sensitive-content checks;
5. bounded authorized PandaData schema/coverage verification;
6. point-in-time industry/concept snapshot verification;
7. separate frozen IC/backtest evaluation.

The bounded live query is interface evidence only. Formal acceptance requires broad coverage, complete-year development/validation/freeze periods, declared costs, and no post-test field or propagation-depth selection.
